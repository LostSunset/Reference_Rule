# Claude Code Instructions

This repository is a reusable reference-rule pack, not an application project.

Claude Code must follow the same rules as Codex:

1. Read `README.md`, `Reference_sources/README.md`, `upstream/README.md`, and `docs/development-logs/README.md` before making changes.
2. Record every non-trivial change in `docs/development-logs/entries/`.
3. Use `docs/development-logs/TEMPLATE.md` for new log entries.
4. Never modify `upstream/repos/*/repo/`; upstream repositories are read-only wrappers.
5. Keep changes small, traceable, and easy to review through pull requests unless the repository owner/admin is performing a direct maintenance push.

Development log entries must not contain secrets, tokens, private credentials, or unrelated personal data.
